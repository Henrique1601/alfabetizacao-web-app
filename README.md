Aplicação web interativa e acessível desenvolvida com um propósito humano: **apoiar o aprendizado da leitura e alfabetização de adultos e crianças**, combinando recursos visuais com síntese de voz nativa em português.

🔗 **Demonstração Online:** [https://alfabetizacao-web-app.vercel.app](https://alfabetizacao-web-app.vercel.app)

---

## 🌟 Funcionalidades Principais

* **🔊 Síntese de Voz Integrada (Web Speech API):** Pronúncia clara, pausada e calibrada (\ate = 0.85\) em português brasileiro (\pt-BR\) para cada palavra apresentada e para as sílabas clicadas.
* **🧩 Formação Interativa de Sílabas:** Apresentação da palavra com ilustração temática e opções embaralhadas para a composição da palavra correta.
* **🎉 Feedback Imediato e Reforço Positivo:** Notificação visual e sonora instantânea após a montagem correta da palavra, estimulando a confiança do estudante.
* **📱 Acessibilidade & Mobile First:** Interface limpa, botões grandes com alto contraste e área de toque generosa, ideal para tablets e celulares.

## 🛠️ Tecnologias Utilizadas

* **Framework:** [Next.js](https://nextjs.org/) (App Router)
* **Biblioteca UI:** [React](https://react.dev/)
* **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
* **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
* **Áudio:** Web Speech API (\window.speechSynthesis\)
* **Deploy:** [Vercel](https://vercel.com/)
